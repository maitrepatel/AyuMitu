## 🚀 How to Run the Website

### Option 1: Direct Double-Click
Simply double-click `index.html` on your computer. It will open in Google Chrome, Microsoft Edge, Brave, Safari, or Firefox instantly.

### Option 2: Live Local Server
If you have Node.js or VS Code Live Server:
```bash
# Using Node's built-in npx serve
npx serve .
```
Then visit `http://localhost:3000`.

## 🎵 How to Use a Custom Song (Optional)
If you want to play a specific romantic song instead of the built-in ambient piano:
1. Place your MP3 file in this folder and name it `music.mp3`.
2. Open `index.html` and check the `<audio id="bg-audio">` tag near the bottom:
   ```html
   <audio id="bg-audio" src="music.mp3" preload="auto" loop></audio>
   ```
3. Whenever Ayu clicks **Music** or **Revisit Our Journey**, your custom song will play!
